Web MAL STAV JANDA s.r.o. / malir-plzen.cz

Nahrání na GitHub Pages:
1) Rozbalte ZIP.
2) Do kořene repozitáře nahrajte přímo soubory index.html, assets/, cenik.html atd.
3) Settings -> Pages -> Deploy from branch -> main / root.
4) Custom domain: www.malir-plzen.cz
5) V DNS nastavte CNAME www -> vase-jmeno.github.io a pro apex A záznamy GitHub Pages.

Úpravy:
- CSS: assets/css/style.css
- Logo: assets/img/logo.svg
- Favicon: assets/img/favicon.svg
- Mapa: iframe v kontaktní sekci v HTML souborech.


Verze v2: doplněna fotogalerie realizací, použita reálná fotografie jako hlavní obrázek a favicon ve formátu PNG/ICO.
